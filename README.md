# ZAUM Influencer Hub 🚀

Интерактивный дашборд для управления инфлюенс-маркетингом. 
Прототип разработан в рамках тестового задания для e-commerce бренда ZAUM.

🌐 **Живое демо:** [Ссылка на ваш GitHub Pages / Vercel]

## 🎯 О проекте
Исходная Google-таблица была преобразована в удобный бизнес-инструмент. 
Главная цель прототипа — избавить менеджера от «горизонтального скролла» и дать собственнику прозрачную картину по экономике интеграций.

**Ключевой функционал первого экрана:**
- **KPI-Сводка:** Общий бюджет, суммарный охват, средний CPM и количество активных блогеров.
- **Интерактивная воронка:** Быстрая фильтрация по статусам (Согласование, Запланировано, Опубликовано).
- **Карточки блогеров:** Вся ключевая информация (площадка, бюджет, охваты) в удобном адаптивном виде.

## 🛠 Технологический стек прототипа
- **Frontend:** Vue 3 (Composition API) + Vite
- **Стилизация:** Tailwind CSS
- **Данные:** Static JSON (выгрузка из демонстрационной таблицы)
- **Деплой:** GitHub Pages

### Почему выбран именно такой подход для MVP?
Согласно требованиям ТЗ (ориентир ~1 час, 100% доступность по ссылке без авторизации, использование только вымышленных данных):
1. **Никаких API-ключей в клиенте:** Исключен риск утечки доступов к реальным Google-сервисам.
2. **Мгновенная загрузка:** SPA-приложение со статичным JSON загружается за миллисекунды, бесплатный хостинг не «засыпает» при неактивности.
3. **Безопасность данных:** Мы работаем строго с изолированной копией данных, не затрагивая реальную инфраструктуру бизнеса.

## 🏗 Развитие в Production (Архитектурное видение)

Как **Backend-разработчик и Системный архитектор**, в реальном продуктовом контуре я бы спроектировал этот сервис следующим образом:

1. **Backend-ядро (FastAPI + PostgreSQL 17):**
   - Перенос мастер-данных из хрупких Google-таблиц в надежную реляционную БД.
   - Использование паттернов *Clean Architecture* и *Repository* для легкого масштабирования логики.
   
2. **Асинхронная синхронизация (RabbitMQ + Celery/Airflow):**
   - Если бизнес-процессы жестко завязаны на Google Sheets, настраивается двусторонний обмен через вебхуки и Google Sheets API в фоновых воркерах, чтобы не блокировать работу основного интерфейса.

3. **Автоматизация и уведомления (Telegram Bot):**
   - Интеграция Telegram-бота (Aiogram) для менеджеров: автоматические алерты за 24 часа до выхода интеграции («Завтра выходит рилс у блогера N, проверьте готовность промокода»).
   
4. **AI-ассистент (Опционально):**
   - Интеграция LLM (на базе LangChain/LiteLLM) для автоматического парсинга условий сотрудничества из переписок с блогерами и занесения их в карточку.

## 💻 Локальный запуск для разработки

1. Клонируйте репозиторий:
```bash
git clone [https://github.com/serker72/zaum-influencer-hub.git](https://github.com/serker72/zaum-influencer-hub.git)
```

2. Установите зависимости:
```bash
cd zaum-influencer-hub
npm install
```

3. Запустите локальный сервер для разработки: 
```bash
npm run dev
```

4. Откройте браузер и перейдите по адресу: [http://localhost:5173/](http://localhost:5173/)
